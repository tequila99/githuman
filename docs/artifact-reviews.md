# Ревью артефактов отложено

По решению ADR 0097 от 2026-10-30 функционал ревью артефактов удалён.
Обсуждения, комментарии, выбор диапазонов строк, блокирующие замечания и
review-команды HTTP/MCP больше не доступны.

Исторические данные и append-only история сохраняются без активного доступа
к обсуждениям. Обычное ревью git diff продолжает работать.

Принятие документов выполняется напрямую из draft через независимую проверку
пакета и разрешение пользователя. См. [жизненный цикл артефактов](artifact-lifecycle.md).
