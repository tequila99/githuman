# Матрица возможностей артефактов

Состояние на 2026-11-01. Матрица описывает фактический продукт, а не план. Столбец
«Проверено» различает: **автотест** — есть тесты `node:test`; **Chromium (фикстура)** —
открыто в браузере на изолированном репозитории с подставным валидатором;
**не проверено** — реализации нет или проверки не было. Проверка с настоящим
ACP-агентом **не проводилась**: все сценарии валидатора идут через фикстуры.

| Возможность | UI | MCP/API | Ограничение | Проверено |
|---|---|---|---|---|
| Создание черновика агентом | нет | MCP `artifacts.create`, `POST /api/agent/artifacts/:operation` | только через запущенный сервер | автотест |
| Просмотр документа | Markdown | `GET /api/artifacts/:id`, `/content` | нет Source и редактирования | автотест, Chromium (фикстура) |
| Поиск и фильтры | поиск по тексту и опечаткам, статус, тип, задача, тег, группировка | `POST /api/artifacts/search` | нет snippets и подсветки в списке, нет переключателя сортировки (новые сверху) | автотест |
| История и выгрузка | оригинал и JSON метаданных с историей | `GET /api/artifacts/:id/export`, `/history` | при известной порче оригинал отключён; сервер проверяет файл всегда | автотест; Chromium (фикстура): JSON метаданных выгружается при повреждённом файле, пункт оригинала отключён |
| Связи и происхождение | связи, предки, потомки | `/relations`, `/ancestry` | — | автотест |
| Исходный путь | в текущих метаданных, если есть | поле `sourcePath` | информационный текст; файл не читается | автотест (хранение), Chromium (фикстура: HTML-символы, пробелы, Unicode, длинный путь) |
| Недоступный текст | метаданные и история доступны, ошибка и «Retry» | — | фоновые события не повторяют чтение | автотест; Chromium (фикстура) только для повреждённого файла, сетевой сбой в браузере не проверялся |
| Смена статуса | кнопка в шапке, диалог, прогресс, отмена, результат проверки | `/api/artifacts/:id/transitions`, `transition-previews`, `/api/artifact-transition-operations` | активные дополнения блокируют archive/delete базы; нужен настроенный ACP-пресет | автотест, Chromium (фикстура); не проверено с настоящим ACP |
| ChangeSet, проверка, разрешение | нет (экран очереди не подключён) | `change_sets`, `validations`, `actions`; HTTP approve и commit | разрешение выдаётся пользователем; очереди запросов в UI нет | автотест |
| Отчёт проверки | окно «Результат проверки» у завершённой операции | `GET /api/artifact-validations/:id`, `/report` | нужен завершённый verdict | автотест, Chromium (фикстура) |
| Задачи и типы | назначение задач в панели чата | `tasks.*`, `types.*` | нет UI создания и редактирования | автотест |
| Source и ревью | нет | нет | удалены или отложены (ADR 0097) | — |

Подробности: [жизненный цикл](artifact-lifecycle.md), [хранение](artifact-storage.md),
[поиск](artifact-search.md), [граф](artifact-graph.md).
